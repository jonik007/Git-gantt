# Git-gantt

Локальная диаграмма Ганта по git-истории репозитория, из которого запущен сервер. Каждая полоса — коммит, каждая строка — ветка, шкала доходит до сегодняшнего дня.

Нужны Node.js и Git. Отдельные пакеты ставить не нужно.

## Запуск

Из корня репозитория:

```bash
node server.js
```

То же самое делает `npm start`. В консоли появится адрес, по умолчанию http://127.0.0.1:4173. Остановите сервер сочетанием Ctrl+C.

Сервер читает историю того репозитория, в котором его запустили (`git rev-parse --show-toplevel`). Чтобы посмотреть другой проект, перейдите в его каталог и запустите команду оттуда.

## Как пользоваться

Страница запрашивает `GET /api/history` и рисует локальные ветки (`refs/heads`).

- В шапке — имя репозитория и счётчики коммитов, веток, авторов и файлов. Имя берётся из URL `origin`, а если remote нет — из имени каталога.
- На шкале зелёная линия «Сегодня». Коммит стоит на дате автора.
- Общий коммит показывается один раз, на самой короткой ветке, которая его содержит. При равной длине предпочтение у `main` или `master`.
- Клик по полосе открывает карточку: короткий хеш, ветка, автор, дата, соавторы из `Co-authored-by`, метки и файлы со статистикой `+добавлено −удалено`.
- Новые коммиты появляются после обновления страницы.

## Настройка

Отдельного файла конфигурации нет. Поведение задаётся переменными окружения и текущим каталогом.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `4173` | Порт HTTP-сервера |
| `HOST` | `0.0.0.0` | Адрес, на котором сервер принимает соединения |

Пример другого порта:

```bash
PORT=8080 node server.js
```

Страница по-прежнему открывается на localhost с тем же портом: http://127.0.0.1:8080. `HOST=127.0.0.1` оставляет сервер только на локальном интерфейсе.

## Проверка

```bash
node --test
```

или `npm test`. Тесты проверяют разбор `git log`, раскладку коммитов по веткам и чтение этого репозитория.
